ข้อสังเกตและวิเคราะห์ผลลัพธ์:

  • Batch Size ขนาดเล็ก: WASM (CPU) เร็วกว่า เนื่องจากไม่มี GPU Dispatch & Memory Copy Overhead
  • Batch Size ขนาดใหญ่: WebGPU (GPU) เร็วกว่า เนื่องจากใช้ประโยชน์จาก Parallel Compute Cores
  • Crossover Point: จุดขนาดข้อมูลที่เวลาการประมวลผลของ WebGPU สลับมาเร็วกว่า WASM
