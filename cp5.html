ข้อสังเกตและวิเคราะห์ผลลัพธ์ (Transformer Model):

  • Batch Size ขนาดเล็ก (1-2 ประโยค): WASM (CPU) อาจทำเวลาได้ใกล้เคียงหรือได้เปรียบด้าน Initialization / CPU Overhead ต่ำกว่า
  • Batch Size ขนาดใหญ่ (4-32+ ประโยค): WebGPU (GPU) จะมีประสิทธิภาพสูงกว่าอย่างชัดเจนจากการประมวลผล Matrix Multiplication แบบขนาน (Parallel Tensor Operations)
  • Crossover Point: ขนาด Batch Size ของข้อความที่เวลาประมวลผลของ WebGPU พลิกมาเร็วกว่า WASM
