หลักการทดสอบ (AI Crossover Stress Test):

  • การเลือก Data Type (dtype): WASM เลือกใช้ q8 (int8) เพราะ CPU มี SIMD instruction สำหรับ int8 โดยตรง ช่วยให้คำนวณเร็วที่สุด ขณะที่ WebGPU เลือกใช้ fp32 เนื่องจาก GPU shader ไม่มี native int8 หากใช้ q8 จะต้อง dequantize เป็น float ทุก operation ทำให้เกิด overhead
  • วัดแบบ End-to-End (init + run): สะท้อนต้นทุนจริงของงาน "เปิดหน้าเว็บมาแล้วประมวลผล N รายการ" โดย init คือเวลาโหลดโมเดล, อัปน้ำหนักขึ้น VRAM และคอมไพล์ Shader
  • จุด Crossover Point: WebGPU มีค่า Init สูงกว่า WASM มาก ส่งผลให้แพ้ตอน Batch ขนาดเล็ก แต่เมื่อ N โตขึ้นเรื่อยๆ ต้นทุน Init จะถูกหารเฉลี่ยจนความเร็วขนานของ GPU ชนะ WASM
